# Project Documentation

This directory contains the technical documentation and methodology for the Banking Data Quality Analysis project.

The project examines data quality issues in a banking customer dataset and demonstrates how Excel VBA automation can be used to standardize inconsistent values, address missing information, and validate targeted corrections.

## Documentation Contents

- Data quality assessment and identified issues
- VBA cleaning methodology
- Correction results and validation
- Limitations and opportunities for improvement

The documentation supports the original VBA source code and visual evidence available in the repository.
